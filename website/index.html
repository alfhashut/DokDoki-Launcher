Supported features

  • Windows and Linux
  • Online Mod Library
  • Separate mod profiles and saves
  • Manual ZIP / 7z installs
  • Ren'Py 6, 7 and 8 support

Before you start

You need your own clean installation of the original Doki Doki Literature Club. Select its folder in the launcher to get started. DokDoki Launcher does not include or download DDLC.

Need help with a bug or a mod listing? Visit Requests or check request status.

DokDoki Launcher is an unofficial, fan-made project. It is not affiliated with, endorsed by, or associated with Team Salvato.
