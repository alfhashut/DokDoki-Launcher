Installation notes

Windows x64: Download and run the EXE. The launcher is currently unsigned, so Windows may show an “Unknown publisher” warning.

Linux x86_64: Download the AppImage, make it executable in your file manager’s permissions, then run it.

Use SHA256SUMS.txt to compare the SHA-256 checksum of your downloaded file. You also need your own clean installation of the original DDLC.

DokDoki Launcher is an unofficial, fan-made project. It is not affiliated with, endorsed by, or associated with Team Salvato.
